# 项目宪章

## 目标

维护一套可以直接上手操作、持续迭代的 AI 手机 UI 和交互设计。继承用户已认可的 V3，而不是重新评估产品是否应该使用 N9 / Sailfish 交互。

手机的主语是“正在做的事”，不是应用图标。AI 负责把意图转成可检查的任务；手势负责指代、比较、暂停、接续与确认。前期实体手机/网页是入口，未来云端个人环境提供连续资料和任务，但本仓库先把体验做清楚。

## 本次 UI 完整范围

86 个登记页面覆盖系统与主要能力，细表在 `SCREEN_CATALOG.md`。它是 0.1.0 的完整 UI 范围，不宣称包含现代手机的一切设置或运营业务。

完成定义包括：可进入页面、有具体内容、可返回/最小化、关键动作有可观察结果、本机与预览分明、可从统一工作台检查。

## 非目标

Android ROM、驱动与无线基带；生产云手机集群；真实 OAuth/支付/订阅/账单；端到端加密账户体系；互联网地图、音乐版权库；真实 LLM、生图、语音服务。禁止用进度动画把这些缺失伪装成完成。

## 优先级

P0 交互语义稳定和用户数据不丢失；P1 操作可学、可逆和无障碍替代；P2 界面密度与美术一致；P3 对接真实能力。远程集成不能反向迫使 UI 变成模拟点击 App 的遥控器。

## 验收负责人

产品最终选择与公开发布由仓库所有者确认。AI 可以在已批准范围内实现、测试和补文档；不能擅自改变品牌、创建收费服务或公开私人资料。
