# 决策记录

## ADR-001 / 接受V3而非重设计方向

用户明确认可V3融合的系统特性。保留三视图、边缘、Peek、活动封面、Pulley、页面确认；反对回到固定App横向轮播+底条。

## ADR-002 / 独立UI仓库

项目暂名 `ai-phone-ui`，展示名SWIPE / AI。不是正式品牌定名，也不是Nokia/Jolla官方系统。专注可维护UI，不复用用户其他项目的私有数据。

## ADR-003 / 公开仓库与快照历史保存（更新）

用户已批准公开仓库和“源码快照 + 原始历史包”。保留原 LICENSE 初始提交，原始五次提交/标签在 bundle 中，不称为远端祖先图导入，不改写历史。此决策替代早先私有建仓与原生历史导入方案。

## ADR-004 / 源模块化，产物单文件

用户要求立即打开，不依赖私密站点。构建产出单HTML，维护时拆分模板/CSS/核心/套件/模型/工作台；以后可迁移框架但需保持交互与单文件体验。

## ADR-005 / 86页是本版范围

覆盖主要系统与能力全景，不等于承诺所有现代手机设置都已完成。实际本机能力和服务预览必须在每页/文档里区分。

## ADR-006 / 无真实凭据与默认网络

所有远端服务未连接；用户数据留本机。静态UI不可承担密钥代理。进入预览确认不代表外部授权或真实发送。

## ADR-007 / 增量保留旧引擎

不抹掉已经认可的V3行为，先用回归测试保护再拆模块。suite函数包装、原生alias与catalog映射属于下一阶段需要统一的技术债。

## ADR-008 / 诚实测试边界

受限浏览器环境采用DOM注入+显式内存存储fixture和CDP触摸；不能称作真机或file-origin实测。CI文件只是配置，实际远端结果另行读取。
