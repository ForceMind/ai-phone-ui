# V4 D2 共享组件

确认正文、文档和笔记采用不透明内容表面；操作菜单沿用单层可降级材质。正文17px、辅助13–14px、按钮至少44px。浅深前景显式定义，避免继承V3青色。来源、版本、未连接提示不得被外观隐藏。照片比较与裁切保持原图和现有action；这里只改善容器、文字和命中区域。

路由范围以screens.json的v4Migration记录为准。原七样板不更改范围，新增24页须core_flows_test逐页浅深截图与退出；三闭环必须运行实际本机下载/一次性确认/候选恢复。物理键盘native测试不等同手机软键盘或读屏。

## D3 分组呈现

系统使用中性控制面与独立暗色息屏；首次使用以标题/说明/下一步为主；AI输入、过程与来源分层；影像保留画面和比较滑杆；资料使用可读纸面；云端服务状态/本机记录明确分层；日常以日历、拨号、封面等实际对象呈现；设置与错误使用成组操作与恢复入口。

标准suite壳以真实标题高度分配阅读区，避免长标题覆盖正文；不改变任务/路由/手势坐标。所有类别仍须native矩阵与像素检查，不能以选择器覆盖数宣布完成。

## 呈现偏好与恢复边界

V3/V4、浅/深/跟随系统、减少透明度和画板保存在当前origin的独立小键，schema白名单验证，最大读取1024字符；不属于业务备份，不跨设备同步。存储拒绝时保留当前交互并明确显示不可持久保存。业务恢复不覆盖此键；V3回退不删除业务资料，之后可回V4。系统外观变化只改变显示，不重复写入偏好。

加强对比度和减少透明度均停用玻璃；设计检查状态层挂在screen顶层而非隐藏任务下方，实际恢复按钮必须可见、可点击并退出。锁/息屏仅是UI，不等同身份认证。

## 设计态输入边界

状态检查面板不是业务确认。存在时同步使底层task/system/系统覆盖/锁屏/息屏/辅助操作inert；pointer和键盘由检查层持有，Escape只关闭检查层。恢复导航沿既有action，移除后由syncAccess依据当前真实状态恢复交互性，不回放旧inert快照。确认payload、一次接受、阅读位置不可被检查层消费。
