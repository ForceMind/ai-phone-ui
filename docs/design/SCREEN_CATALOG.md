# 完整界面清单 — 0.1.0

共 86 个页面；55 个页面含本机可执行交互，31 个主要展示服务契约或能力预览。此计数不是功能完成率。

以 `src/data/screens.json` 为唯一机器目录。UI完整 = 登记范围全部可检查；不意味着每个外部服务已经接入。父级为信息架构归属，原生V3别名的直接目录入口可能从根任务进入。

每页均必须具备可观察内容、明确模式、返回/最小化路径和恢复入口。公用状态检查不是独立业务实现。

## 逐页验收契约

所有页面可从桌面目录或手机端目录定位。目录直接定位不是唯一正常入口，用户旅程详见USER_FLOWS。

### SYS-01 活动任务

目标：持续任务封面与直接操作。

渲染类型：`home`；定位：`#screen=SYS-01`；父级：`root`。

操作边界：可在本机检查内容和相关动作；不因页面是local就宣称第三方服务已接入。

离开：通过系统空间/侧边最小化/明确关闭入口离开；锁屏、息屏采用各自唤醒路径。

验收：入口可达、正文可见、输入保留、恢复/退出可达；对应自动化route检查不能替代真机业务验收。
