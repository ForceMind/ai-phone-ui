# 手势与状态契约 v1

## 总则

所有距离用 **360×672 逻辑屏幕坐标**，显示缩放后先换算。以下为本项目参数，不是 Nokia / Jolla 官方硬件阈值。手指或鼠标的画面反馈即时处理，大模型不得参与判断“返回/暂停/确认”。

## 优先级

输入框、选择框、滑块的原生交互优先；多指会取消当前单指动作。其次为锁屏/覆盖层；再处理从明确屏幕边缘发起的系统手势；随后处理确认页/子页返回、已滚动内容、活动封面、拉绳菜单和图片版本。方向在移动超过 8 逻辑像素后锁定，避免小抖动变成操作。

活动封面动作：照片比较已有版本；整理封面向右开始/暂停/继续，向左看已完成结果；专注向右开始/暂停，向左复位；笔记向右请求浏览器朗读、向左进入导出确认。新增服务封面使用明确本机预览或保留草稿动作，不能伪装真实云端控制。

## 页面栈与草稿

最小化前保存 taskId、stack、可恢复阅读位置和输入草稿。侧边 Peek 不触发重新渲染；手指尚未松开时不能重置模型会话、切版本或创建新任务。子页返回只改变 stack，不结束 Task。

同一手势触发的后续浏览器 click 有短抑制窗，防止滑完又点中底层控件。抑制窗必须在测试里验证，不可延长到使正常点击失灵。

## 执行安全

确认页面绑定 `actionId + versionId + payload snapshot`。后台产生新版本不能替换已经展示的确认内容。返回、最小化、权限拒绝、超时、网络错误都不是“同意”。重试由未来执行器提供幂等保证，本版只有本机一次性消费。

## 触摸与滚动边界

已滚动内容的下拉用于滚回顶部；滚到顶后的新下拉才可选择 Pulley。文本选择、系统键盘与滑杆不能触发页面退出。Web 原型只捕获自己内容内手势，无法接管真实 Android/iOS 全局边缘；真机边缘冲突是独立待验收项。

## 反馈

动作过程中给短文案，松手后给结果。错误提示保留当前对象。氛围改变不改变手势映射。减少动效时仍有最终状态、选择词语和颜色之外的标记。辅助按钮可在设置开启，但默认不回退成底部导航栏。

## 备份恢复确认的存储验收

UI-011 使用 CLD-17 / SET-10 的文件输入与现有明确确认按钮，不改手势阈值。成功必须在同一个快照提交 core/suite 后才 reload；文件选择本身、格式或大小拒绝、配额失败、取消均不得替换旧资料。配额失败保留可再次点击的同一确认，取消后重新选择文件须重新确认。HTTP-origin 自动化验证真实持久化和 reload，不等同实机触摸、读屏或系统存储压力。

备份内的图片必须在替换确认出现之前经过浏览器加载、尺寸和解码检查。空 source 仍表示本机示例；可解码的 1600 万像素原片可恢复，超过上限或无法解码的 data URL 必须拒绝。校验不重编码、不裁切原片。较新的文件选择或离开原页面后，过时的异步校验不能重新打开确认或清空新候选。普通照片导入的 1400px 工作副本策略保持不变。


UI-014 键盘补充：确认页进入与接续优先聚焦取消，Tab / Shift+Tab 在两个既有按钮中循环；Escape 等价于取消。返回恢复有效原任务/入口，不等价于接受；照片导入的取消恢复发起任务，明确接受仍去照片工作区。鼠标/触摸确认阈值、右滑取消、反转和 pointercancel 不改。较新的任务导航使旧文件选择失去恢复焦点或重开确认的资格。


## 现有导入确认的候选归属

照片 File 与已校验备份只属于创建它的确认。现有任务栈的浅复制共享同一个候选持有对象；接续旧确认不会取用较新文件。取消清空该确认的候选，接受照片在启动异步导入前一次性取走自己的 File；恢复只有在单快照提交成功后才清空候选，写入失败仍可重试。较新文件被取消或校验失败不改变旧确认，旧会话副本不能重放已消费/取消的候选。仅保留原有确认文字与页面，不扩展全局状态层。


## DAY-05 长消息确认阅读

现有确认正文使用同一个 stack-scroll 区域：纵向拖动只滚读，横向确认阈值、反向回推、pointercancel 与右滑取消不改。滚轮或阅读键不消费确认，页面中的固定文字与末尾本机预览说明都能读到；最小化/跨任务接续复用原有滚动位置保存。接受仍只记录 local-preview-only，取消保留完整草稿，未调用消息服务。
