# 设计系统 v1

## 视觉基调

保留 V3 的青色 N9 式一体机身、薄字重、全屏内容、几乎无圆角的活动封面。组件服从系统空间，不改成通用 SaaS 卡片墙。设备外的工作台采用深青底，以免抢走内容。

三种氛围：海雾、暮色、夜航。背景、面板、强调色与设备外壳同步变化。颜色表达状态时必须配文字或图形，不能只凭红绿判断。

## 层级与空间

逻辑内容 360×672；侧边标准内距 24；系统标题31/32；正文14–17；辅助文字10–12；封面标签8–10。本版小字是桌面缩放原型遗留，不能直接等同真机可读尺寸；下一阶段必须按 CSS像素/物理密度再校准。

头部保留侧向页点与拉绳提示，不加入常驻返回/主页按钮。任务空间和系统空间有明确前后层级；弹层仍要能退出。

## 共用组件

`ScreenHeader` 编号仅在设计预览可见；`ModeChip` 区分本机与未连接；`ActionRow` 仅在可点击时使用 button，纯描述用静态行；`FormField` 保留草稿、原生焦点；`PulleyMenu` 三项优先动作；`ActiveCover` 小面板共享状态；`Confirmation` 固定快照；`VersionRail/Gallery` 比较派生图；`LocalNotice` 不冒充云端消息；`StateView` 空/错/离线/加载；`AlternativeControls` 默认关闭。

## 界面密度

主页面最多一个主目标；次要操作放拉绳/子页。不能为“展示86页”把所有模块塞到消费者主页。云端总览只呈现连接边界、任务和权限入口；详情层再展示日志/预算等。

## 参数维护

`src/data/tokens.json` 当前是参数目录，不是完整自动编译 token 引擎；CSS与核心手势仍需同步修改。修改任何阈值必须增加正向/反向/取消测试。实际渲染优先于文档中的理想数值。

## 资源

内置风景由 Canvas 生成；图标由 SVG paths 组成；字体使用设备自带字体栈。没有网络图片依赖，也没有打包字体二进制。勿加入 Nokia/Jolla 标志来暗示官方产品。
