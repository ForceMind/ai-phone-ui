# 全流程交互设计

## F01 首次开始

ONB-01 欢迎 → ONB-02 使用意向 → ONB-03 本机昵称 → ONB-04 手势教学 → ONB-05 云端边界 → SYS-01。

可跳过教学；所有相机/麦克风许可在真实使用时另行请求。选择使用意向不是设备授权或云端登录。拒绝许可不阻止笔记和导入图片。

## F02 拍摄到成品

IMG-01 原生相机/导入 → IMG-02 原图工作区 → 点选位置 → 内部下拉暖调 → IMG-03 版本 → IMG-08 比对 → IMG-04 可选中心裁切 → IMG-09 固定导出确认 → PNG。

允许中途 Peek/最小化，重进保留版本。改图保留原始版本。裁切导出是副本而非改写源图；生成式背景替换在 IMG-06/07 仅保存要求，不能伪装成本机调色结果。相机拒绝转 ERR-03 → 导入。

## F03 继续交代

AI-01 输入“记下：…” → 实际写入 DOC-02 → AI-08 看引用上下文 → AI-07 看会话。

“暖一点”新增照片版本；“开始整理”调用本机原文整理。无匹配规则时明确告诉用户尚未接入模型，不自动编造回答。AI-02 展示语音许可和校对入口，需用户触发浏览器识别。

## F04 计划、审批、成果

AI-01 → AI-04 执行计划 → AI-05 查看交付范围 → 手势确认 → AI-06 成果入口。

服务尚未连接，确认只记录本机预览。取消返回原页；后台新版本不能改变本次 snapshot。未来 adapter 应携带幂等键、明确目标、费用上限和执行回执。

## F05 整理笔记与任务接续

DOC-02 写笔记 → CLD-03 整理 → 侧边推开 → SYS-01 横滑整理封面暂停/继续 → 重新打开 → 结果 → 导出。

整理基于开始时原文快照，提取非空行去重；不是 AI 概括。网页转入隐藏/退出会暂停，重新进入不会假装在云端完成。CLD-04展示各步，CLD-13/16展示本机记录。

## F06 消息与确认

DAY-03 示例联系人 → DAY-05 草稿 → “审阅草稿” → 固定接收方/文字确认 → 左滑记录本机预览，右滑取消。

本机预览记录明确标注未实际发送。输入尚未发送时切换任务，原草稿保留。无真实联系人连接、推送或电话权限。DAY-06/07/08只展示拨号/来电/通话状态。

## F07 日程与周期任务

DAY-01 → DAY-02 保存本机日程；CLD-11 → CLD-12 名称/频率/时区/时间 → 保存草稿 → 周期列表。

没有日历写入、邀请或服务端调度。草稿始终未启用；恢复备份也不能自动启用。真实接入后必须显示下一次运行的绝对时间、时区及最近结果。

## F08 权限与服务

CLD-08 未连接服务 → CLD-09 范围详情 → 预览确认 → CLD-10 权限中心 → CLD-16 本机审计。

演示授权不能改变连接为 ready，不发送外部 OAuth。模型密钥不出现在前端；SET-05只说明连接边界。

## F09 明确记忆与忘记

SET-07 明确偏好 → SET-08 编辑/停用 → ERR-08 删除该条 → 手势确认 → 列表少一条 → 撤销恢复。

删除仅针对固定 ID；不得清空别人的偏好、笔记或原图。撤销仅在当前运行会话可用，未提供生产级多版本回收站。

## F10 迁移与恢复

SET-10 或 CLD-17 → 导出 JSON → 自行保管 → 选择备份 → 校验 format/schema/大小/图像地址 → 显示替换范围 → 明确确认后恢复并重新载入。

非法内容不替换旧资料；恢复后整理暂停、专注不自动开启、远端保持未连接。失败应保留原资料。浏览器下载与文件落盘不能混称“云端已保存”。

## F11 异常接续

加载可停止，失败展示保留范围；离线提供本机编辑；额度页只保存草稿；许可拒绝可以导入；待审批不自动执行。ERR-01..08都有明确恢复/退出入口。工作台状态切换不会改变真实网络。
