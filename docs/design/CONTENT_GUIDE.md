# 文案规则

优先“当前对象 + 状态 + 下一步”。例如“这张照片已新增一个暖调版本；原图保留。”不要“AI魔法处理中”“一切交给我”掩盖具体动作。

| 场景 | 使用 | 不使用 |
| --- | --- | --- |
| 服务未接入 | 交互预览 · 未连接 | 在线 / 已授权 / 服务健康 |
| 本机预览消息 | 已记入本机预览，没有发送 | 已发送成功 |
| 下载 | PNG 已交给浏览器下载 | 已永久保存 |
| 周期草稿 | 已保存草稿，未启用定时任务 | 我会每周替你执行 |
| 权限意向 | 使用时仍会请求设备权限 | 你已授予相机权限 |
| 图片处理 | 本机调色版本 | AI 已重建真实细节 |
| 错误 | 保留输入；该步骤未完成 | 出错了，请稍后再试（无恢复方式） |

英文只保留品牌、结构标签和开发标识，交互正文采用简体中文。设计检查编号不等于正式产品中要展示开发代码。
