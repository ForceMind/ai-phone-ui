# 响应式与设备适配

桌面工作台使用三列：页面目录 / 设备 / 当前规范。中间逻辑屏幕固定360×672，机身390×756，按剩余宽高缩放，不独立缩放手势阈值。

小于730px宽时目录与检查器隐藏，顶端“界面目录”打开全屏目录；页面主体只展示可操作手机。可以鼠标、触摸或键盘操作。

建议矩阵：390×844、360×800、430×932、768×1024、1366×768、1440×1000；另测横屏、200%文字缩放、浏览器地址栏收缩和软键盘。

本版本保留拟真机身，是用户要求的网页手机，而不是上线的手机端消费者布局。将来真正安装为系统壳时去掉外层机身和工作台，不改变系统手势语义。

已做模拟触摸与若干视口检查；实际Android/iOS浏览器系统边缘、视口resize和相机许可仍待实机验收。不得宣称网页已经取代系统导航。
